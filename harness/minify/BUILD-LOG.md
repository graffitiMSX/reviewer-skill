## Global constraints (binding on every task)

- Python 3.13, stdlib only. No pip installs. Tests use `unittest`, not pytest.
- Suite command: `python3 -m unittest discover -s harness/minify/tests -t .` from repo root.
- Every hook always exits 0, never emits a blocking decision.
- Hooks read only `tool_name`, `tool_input`, `cwd`, `session_id`. Never the tool result.
- Never install or download a formatter.
- Logs at `~/.claude/minify-harness/<project-slug>/`. Nothing written inside the project.
- Every module takes `home=` so tests never touch the real `~/.claude`.
- Half-up rounding `_r(x) = int(x + 0.5)`; never Python's `round()`.
- Language classes defined once, in `lib/classes.py`.
- Commit after every task.

### Rulings made before execution

Ruling R1: `detect()` must probe the `npx --no-install prettier` fallback (memoized
`_npx_prettier_ok()`, version-string check) and return it only when it actually runs —
verified failing on this machine, where `npx` exits 0 while reporting a missing package.
Why: an unusable formatter reported as usable makes `doctor` call `ts`/`css`/`json` safe,
so the harness would minify files it cannot un-minify, defeating the spec's Guard 3. It also
kept T14's skip guard from firing, turning 3 skips into 3 failures. Plan amended: T5 gains the
probe, one test, and a rewritten ordering note; T5's expected count 9 → 10; T9's 9+9 → 9+10;
T5's two npx-dependent tests now patch `_npx_prettier_ok` instead of `shutil.which`, because
the probe memoizes. Cost if wrong: one extra subprocess per process, and a transient probe
failure would under-report a language as unsafe — the conservative direction.

Ruling R2: T11's test must `import importlib.machinery` explicitly. Verified: `import
importlib.util` alone leaves `importlib.machinery` unresolvable (AttributeError), so the CLI
test would have crashed on load. Cost if wrong: none, it is a strictly additive import.

Ruling R3: T14's eight fixture code blocks that carry no in-content filename are now labelled
with their filename above each block. Why: the JSON, TS, CSS and JS pairs were distinguishable
only by reading order, and a transposed pair would silently invert the equivalence proofs.
Cost if wrong: none, labels are prose.
